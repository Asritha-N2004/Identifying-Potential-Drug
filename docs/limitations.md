# Known limitations

- Synthetic fixtures remain available separately. A bounded real Open Targets/Europe PMC snapshot and three real disease case studies are now implemented. Automated mappings use explicit source identifiers; clinical claim verification and literature interpretation still require expert review. No clinically validated repurposing discovery is claimed.
- Real-candidate literature metadata and openFDA label text retrieval are implemented for up to three highest-model-score candidates. Claim adjudication, label identity/formulation review and clinically validated safety assessment are absent. Candidate literature and pharmacology components remain zero. Synthetic runs report evidence gaps without network calls.
- R-GCN is a working relation-aware model. Node2Vec, GraphSAGE, ComplEx, random walk baselines, molecular fingerprints and PyTorch Geometric conversion are not implemented.
- Random transductive pair split only. No temporal, grouped publication, cold-start, drug/disease-stratified evaluation or confidence intervals. Sampled controls are unlabeled, not confirmed negatives. No PU estimator.
- All TREATS and INVESTIGATED_IN edges are excluded from message passing and structural features. All clinical pairs are excluded from unlabeled controls and candidate generation. Only genetic-association datatype scores create disease-gene edges; target selection is still aggregate-ranked and drug selection is approval-based. These ascertainment biases remain, along with correlated upstream evidence and the absence of temporal filtering.
- Ranking weights are configurable; biological and pharmacological score calibration is not validated. Sigmoid outputs are uncalibrated and path proximity is connectivity only.
- Paths are post-hoc graph evidence. Trained-model single-edge occlusion recomputes scores for up to 12 path edges, removing both forward and inverse message-passing instances. It measures computational sensitivity, not biological causality or exhaustive attribution. SHAP, Integrated Gradients and GNNExplainer are not implemented. Centrality is descriptive.
- Agent input state is typed but each stage output is not independently Pydantic validated. Stages use a fixed sequence; hard worker termination, resumable execution and distributed task queues are absent.
- PostgreSQL 16.15 and Neo4j Community 5.26.33 native integration is verified, including actual HTTP workflow execution and application/database restart persistence. Linux-container execution remains unverified. Neo4j query serving, schema migrations, release rollback and synchronization deletions are absent.
- Connectors do not implement every source-specific schema, pagination mode, bulk download or incremental release update. API availability and licenses must be verified.
- The API is intended for a local single user. Optional shared API key is not a multi-user authentication system. Training consumes compute. Do not expose the service publicly without access control, request quotas, process isolation and operational review.
- Frontend uses system font fallbacks offline. Production bundle is larger than Vite's default warning threshold; code splitting remains an optimization.
- Docker CLI and standalone Compose are available; deployment/test configuration validation passes. Docker Desktop/engine and WSL are absent, so container builds, container healthchecks and full Compose startup remain unverified. See deployment results for the exact engine connection failure.
